# LitPlanz v2.1 — App Store Preview Recording Script

**Target length:** 25–28 seconds (Apple's window is 15–30s).
**Target resolution:** 886 × 1920 portrait, 30 fps (Apple's universal preview size). Either record at this size or use the conversion script in [`tools/`](../tools/) to letterbox after the fact.
**No voice-over needed.** App Preview audio is optional and the snake-path animation + UI interactions tell the story.

---

## Pre-flight checklist

Before hitting record, get the simulator/device into a clean state:

- [ ] Signed in as **`demo@litplanz.com`** (Pro account, tokens reset to 7)
- [ ] At least 2–3 saved Vibez already in the Saved tab (so newest-first sort shows visible reordering)
- [ ] City selector pre-populated with **Berlin** (cached → instant generation on Take 2 below)
- [ ] Theme pre-selected: **Rooftop**
- [ ] Status bar: 100% battery, full signal, hidden notifications (`Settings → General → AirPlay & Handoff → Status Bar Override` on iPhone, or use the simulator's status bar overlay)
- [ ] Map embed cache warmed (open one plan once before recording so polylines render instantly)
- [ ] Screen recording: Control Center → red dot, OR `xcrun simctl io booted recordVideo --codec=h264 ~/Desktop/preview-raw.mov`

## Shot-by-shot script

### 0:00 – 0:04 · Tap to generate
- App is on the BoltView (the Vibez generation screen)
- City chip shows **Kampala** (uncached, so the animation has time to shine)
- Theme chip shows **Rooftop**
- Tap the bolt button → snake animation fires

### 0:04 – 0:11 · Showcase the snake animation
- Hold steady on the snake-path animation as it traces top to bottom
- Watch all 3 location pins pop in with the spring bounce
- Animation loops once forward, retreats, loops again — capture about 1.5 full cycles
- This is the visual centerpiece — give it room to breathe

### 0:11 – 0:14 · Plan card appears
- Generation completes, plan card slides up with all 3 venues
- Quick pan/scroll down so the route map embed enters frame

### 0:14 – 0:19 · Map embed → tap top-right button
- Tap the top-right map button on the embed
- Cut to Google Maps opening with the **full multi-stop route** drawn between all 3 venues
- Hold for a beat so the connected route is clearly visible

### 0:19 – 0:24 · Back to app → tap a pin → Apple Maps
- Swipe back to the LitPlanz app (or simulate via cut)
- Tap an individual pin on the route map
- Cut to Apple Maps opening with that **single venue and driving directions**
- This shows the "single venue" alternative

### 0:24 – 0:28 · Saved tab → newest at top
- Swipe back to LitPlanz
- Tap the Saved tab in the nav bar
- Show that the just-generated Kampala Rooftop plan is now **at the top** of the saved list (above older Berlin/NYC plans)
- Hold on this final frame for ~1s so it lingers in memory

### End

## Cuts that work well as transitions

- **Tap → app switcher → other app** = use a quick whip-pan or 1-frame black flash
- **Inside the same app** = no cut needed, real-time motion is more authentic
- Don't use slow fades — Apple App Reviewers (and viewers) prefer snappy real-app feel

---

## What NOT to capture

App Review will flag and reject videos containing any of these:

- Sign-in screen, paywall, or any price-visible UI (your test account is Pro so this shouldn't happen, but double-check no Pro-upgrade modal flashes)
- Apple Pay or third-party login buttons
- Notifications, calls, or banners from other apps
- The Apple Maps "ask for current location" prompt (our v2.1 deep links specifically avoid this — but watch for stray system alerts)
- Other apps visible (only the app switcher cuts to Google Maps and Apple Maps are explicitly allowed because they're part of the showcased feature)
- People or children's faces on the screen

## Post-record steps

1. **Trim to exactly 25–28s** in QuickTime (`Edit → Trim`)
2. **Verify resolution is 886 × 1920** (or any of Apple's accepted resolutions — see [`whats-new.md`](./whats-new.md) for the full list)
3. **If wrong resolution:** run the conversion script:
   ```bash
   swift tools/resize-app-preview.swift \
     ~/Desktop/preview-raw.mov \
     ~/Desktop/preview-886x1920.mp4 \
     886 1920
   ```
4. **Verify with QuickTime → Window → Show Movie Inspector**:
   - Duration: 15–30s
   - Format: H.264, 886 × 1920
   - File size: under 500 MB
5. **Upload to App Store Connect** → My Apps → LitPlanz → version `2.1` → Previews and Screenshots → leftmost slot of the relevant device size row

## Timing reference for v2.1 specifically

The snake-path loading animation is **3.2 seconds per cycle**. Pipeline generation typically takes **20–25 seconds** end-to-end for uncached cities. So:

- Uncached generation (e.g. fresh Kampala) = ~6–7 snake loops visible
- Cached generation (e.g. repeat Berlin) = **instant**, snake animation only flashes briefly

For the preview, **use an uncached city** so the animation gets at least 2–3 full cycles on screen. That's the visual headline feature for this release.
