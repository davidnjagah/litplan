  - Size: 48px

  - Font: SF Pro Text Medium
  - Size: 28px
  - Color: Light Grey (#AEAEB2)
  - Shadow: 0px 1px 4px rgba(0,0,0,0.4)

### Background Treatment
- Semi-transparent dark overlay: rgba(0,0,0,0.6)
- Blur effect: 8px Gaussian blur
- Padding: 40px horizontal, 30px vertical
- Corner radius: 16px

### Positioning
- Top margin: 100px from top edge
- Bottom margin: 100px from bottom edge
- Horizontal: Centered with 60px left/right margins

## Production Workflow

### Step 1: Prepare App UI
1. Build and run app on iPhone 15 Pro Max simulator
2. Load high-quality mockup data into app
3. Navigate to each screen (Home, Plans, Group Flow, Paywall, Profile)
4. Ensure perfect UI state (no loading spinners, complete data)

### Step 2: Capture Screenshots
1. Use Xcode Simulator screenshot tool (Cmd+S)
2. Capture each screen at 100% scale
3. Export as PNG files
4. Verify dimensions (1290x2796px)

### Step 3: Add Text Overlays
1. Import screenshots into design tool (Figma, Sketch, Photoshop)
2. Add semi-transparent background overlays
3. Add headline and subtext with proper typography
4. Apply shadow effects for readability
5. Export as PNG with maximum quality

### Step 4: Create Size Variants
1. Scale screenshots down to 1242x2688px (6.5" display)
2. Scale screenshots down to 1242x2208px (5.5" display)
3. Verify text remains readable at smaller sizes
4. Adjust text sizes if necessary for smaller displays

### Step 5: Quality Assurance
1. View all screenshots at 100% zoom
2. Check for pixelation, blurriness, or artifacts
3. Verify text overlays are readable
4. Confirm screenshots accurately represent app functionality
5. Test on actual devices if possible

### Step 6: App Store Upload
1. Log into App Store Connect
2. Navigate to app listing
3. Upload screenshots for each device size
4. Order screenshots: Home → Plans → Group → Paywall → Profile
5. Preview on different device sizes
6. Save and submit for review

## App Store Guidelines Compliance

### DO's
- Show actual app screens (no mockups)
- Use high-quality images
- Ensure text is readable
- Maintain consistent design language
- Show diverse features
- Use real-looking data

### DON'Ts
- No competitor comparisons
- No fake reviews or ratings
- No exaggerated claims
- No device frames (Apple adds them)
- No landscape orientation (portrait only for iPhone)
- No outdated iOS elements

### Localization (Future)
Screenshots should be localized for major markets:
- English (US, UK, Canada, Australia)
- Spanish (Spain, Mexico, Latin America)
- French (France, Canada)
- German (Germany, Austria, Switzerland)
- Portuguese (Brazil)
- Japanese (Japan)
- Korean (South Korea)
- Chinese Simplified (China)
- Chinese Traditional (Taiwan, Hong Kong)
